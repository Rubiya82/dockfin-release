DockFin
기능시작하기보안다운로드

Windows · Android · LAN

내 PC 화면을,
끊김 없이 어디서나.

DockFin은 GPU 화면 캡처와 하드웨어 H.264 인코딩으로 지연을 최소화한 원격 화면 공유 프로그램입니다. 다른 PC나 Android 휴대폰에서 화면을 보고, 허용된 경우 마우스와 키보드로 조작할 수 있습니다.

무료 다운로드사용 방법

가장 빠르게

DXGI 데스크톱 복제 → GPU 색 변환 → NVENC / Quick Sync / AMF 하드웨어 인코딩. 변화가 있을 때만 프레임을 보내 LAN에서 수 ms 지연.

제어 / 보기 전용

제어 비밀번호와 보기 비밀번호를 따로 둘 수 있습니다. 보기 전용 접속은 호스트가 입력을 무시합니다.

간편한 접속

LAN 자동 검색, 1회용 6자리 코드, 호스트 승인 요청, 한 번 인증한 기기 기억(페어링).

Android 앱

하드웨어 디코딩, 터치/트랙패드 모드, 핀치 확대, 소프트 키보드와 특수 키, 클립보드 전송.

멀티 모니터 · 클립보드

보고 싶은 모니터를 바로 전환하고, 텍스트 클립보드를 양방향으로 동기화합니다.

검증된 자동 업데이트

배포 서명(ECDSA P-256)과 SHA-256을 확인한 뒤에만 설치합니다. 실패하면 이전 버전으로 복구합니다.

시작하기

  1. 공유할 PC에서 DockFin.exe를 실행합니다. 화면에 PC 이름, 주소, 1회용 코드가 표시됩니다.
  2. 보는 PC 또는 휴대폰에서 DockFin을 열면 같은 네트워크의 PC가 자동으로 나타납니다.
  3. PC를 고르고 1회용 코드(또는 설정한 비밀번호)를 입력해 연결합니다. "이 기기 기억"을 켜면 다음부터 바로 연결됩니다.

보안

모든 연결은 ECDH P-256 키 교환과 AES-256-GCM으로 암호화됩니다. 비밀번호는 PBKDF2로 유도된 증명값만 오가며, 저장된 비밀값은 Windows DPAPI / Android Keystore로 보호됩니다. 5회 연속 인증 실패 시 해당 주소는 5분간 차단됩니다.
